# 🚀 Batch Processing Calculator v1.0

A high-performance command-line calculation utility built completely from scratch in Python. This project was created out of a **pure love for making things** and serves as a solid logical refresher to restart my programming journey before jumping headfirst into **GDScript** for game development! 🎮

---

## 🛠️ Feature Roadmap

This calculator doesn't just process two numbers—it ingests entire batch data rows, validates the inputs, and maps or accumulates operations sequentially from left to right inside a custom-designed cyberpunk terminal layout framework (`┌───┐`).

### 🔢 Mathematics Suite
*   **Basic Core:** Addition (`+`), Subtraction (`-`), Multiplication (`*`), Division (`/`)
*   **Normalised Suite:** Exponent (`xʸ`), Square (`x²`), Square-Root (`√`), Cube (`x³`), Cube-Root (`³√`)
*   **Advanced Logic:** Modulus (`%`), Factorial (`!`) *(Supports massive, astronomy-sized integer calculations natively!)*

---

## 💻 Tech & Design Patterns
*   **Stack accumulators & Data Mappers:** Custom written logic using `.pop(0)` list shifting mechanics to guarantee standard linear execution flow.
*   **Input Guard Rails:** Strict terminal string splitting (`.split(",")`) with array length verification to capture human typing errors before code compilation.
*   **Zero-Trap Defenses:** Edge case armor protecting against division-by-zero crashes and infinite loops on zero-factorials (`0! = 1`).

---

## 🚀 How To Run It

1. Make sure you have **Python 3** installed on your operating system.
2. Clone or download this repository file to your machine.
3. Launch your terminal, navigate to the folder, and run:
   ```bash
   python main.py
   ```
4. Enter your input count, type your numbers separated by commas, select an option from the dashboard grid, and watch the batch logic execute!
